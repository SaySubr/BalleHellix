# 🔧 Настройка SessionManager

## 📋 Что нужно сделать

### 1. Создать GameObject с SessionManager

```
1. Открой GameScene.unity
2. Создай пустой GameObject → назови "SessionManager"
3. Добавь компонент SessionManager
4. Готово!
```

### 2. Проверить что работает

```
1. Запусти игру
2. В консоли должно быть:
   - "🎲 Новая генерация: высота=X, seed=Y"
   - "💾 SessionManager: сохранена башня..."
3. Нажми "Заново"
4. В консоли должно быть:
   - "🔄 Рестарт: высота=X, seed=Y" (те же значения!)
5. Нажми "В меню"
6. Запусти снова
7. В консоли должно быть:
   - "🎲 Новая генерация..." (новые значения!)
```

---

## ✅ Что исправлено

### 1. Рестарт уровня
- `SessionManager` хранит данные между сценами
- `TowerGenerator` читает высоту из `SessionManager`
- `ObstacleGenerator` читает количество из `SessionManager`
- При рестарте — те же значения!

### 2. Подсчёт блоков
- `GetRemainingBlocks()` теперь фильтрует блоки
- Считает только активные и не разрушенные
- Показывает правильное количество!

### 3. Выход в меню
- `ResetForNewGame()` сбрасывает `SessionManager`
- Следующий запуск — новая генерация

---

## 🐛 Если не работает

### Рестарт не сохраняет:
- Проверь что `SessionManager` есть на сцене
- Проверь что компонент не disabled

### Блоки считаются неправильно:
- Проверь что `TowerGenerator` назначен в `LoseSystem`
- Смотри консоль при разрушении блоков

### Сброс не работает:
- Проверь что `WinSystem` и `LoseSystem` вызывают `ResetForNewGame()`
- Проверь что `SessionManager.Instance` не null
